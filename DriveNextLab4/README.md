# DriveNext — лабораторная работа №4

Самостоятельный Android-проект на Kotlin (минимальная версия Android 12), реализующий:

- экран деталей автомобиля;
- добавление и удаление избранного через Room (`Entity`, `DAO`, singleton БД);
- список избранных автомобилей;
- оформление аренды с выбором дат;
- расчётные блоки стоимости и экран успешного бронирования;
- сохранение сессии через SharedPreferences.

## Запуск

1. Откройте папку `DriveNextLab4` в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите приложение на эмуляторе или устройстве с Android 12+.

Авторизация и отправка регистрации пока работают в демонстрационном локальном режиме; подключение Supabase выполняется после добавления ключей проекта.
