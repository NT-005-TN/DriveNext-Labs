# DriveNext — лабораторная работа №1

Android-приложение на Kotlin (минимальная версия Android 12), реализующее:

- стартовый экран DriveNext продолжительностью 2,5 секунды;
- проверку подтверждённого интернет-соединения;
- экран отсутствия сети с повторной попыткой;
- onboarding из трёх слайдов на `ViewPager2`;
- кнопки «Пропустить», «Далее» и «Поехали»;
- сохранение прохождения onboarding в `SharedPreferences`;
- разделение на `data`, `domain` и `presentation`, ViewModel для логики экранов.

## Запуск

1. Откройте папку `DriveNextLab1` в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите приложение на эмуляторе или устройстве с Android 12+.

Для повторной проверки onboarding очистите данные приложения в настройках устройства.
