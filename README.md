# DriveNext — лабораторные работы

Пять отдельных Android-проектов по разработке мобильных приложений.

| Папка | Работа |
| --- | --- |
| DriveNextLab1 | Заставка, проверка сети, онбординг |
| DriveNextLab2 | Экраны входа и регистрации |
| DriveNextLab3 | Каталог, поиск, профиль и настройки |
| DriveNextLab4 | Карточки автомобилей, избранное и бронирование |
| DriveNextLab5 | Сценарий добавления автомобиля |

Открывайте нужную папку DriveNextLabN в Android Studio как отдельный проект.
Укажите установленный Android SDK и используйте совместимый Gradle JDK (например, JDK 21).
Для сборки перейдите в папку лабораторной и выполните `./gradlew assembleDebug`.

Кэши, результаты сборки и локальные настройки SDK в репозиторий не включены.
Лабы 2–5 используют Supabase Auth вместо демонстрационных токенов.
Для лаб 3–5 применена миграция каталога/бронирований и настроены отдельные OAuth callback.
В Supabase: профили, 5 учебных автомобилей, бронирования, приватные хранилища
registration-documents и car-photos. SQL-проверки расчётов, конфликтов дат, отмены,
публикации и разделения доступа прошли с откатом тестовых данных.
Полная приёмка ещё требует пользовательского Google/email-входа и прохода экранов
с загрузкой файлов через приложение; эти проверки не подменяются SQL-тестами.

Канонические исходники находятся в этом Git-репозитории. Соседние папки
`../DriveNextLab1`–`../DriveNextLab5` должны содержать те же исходники;
проверка различий — `sh scripts/check_lab_copies.sh`.

## Дополнительные материалы

- `materials/demo_photos/` — две тестовые картинки для выбора файлов в приложении; это не настоящие документы.
- `materials/archive/defense/` — старый Word-сценарий защиты ЛР1–2 и скрипт его создания.
- `materials/archive/videos/` — пять ранних записей демонстрации ЛР1–2.

Архивные материалы подготовлены до перехода на настоящую авторизацию Supabase.
Указанные там номера строк, описание demo_token, поведение экранов и демонстрация
Google-входа не соответствуют текущему коду. Архив сохранён для истории, а не как
подтверждение готовности текущей версии. Актуальные исходники и статус проверки —
в папках DriveNextLab1–DriveNextLab5 и их README.

Секреты, пользовательские данные Supabase, локальные настройки Android Studio,
кэши и промежуточные сборки в Git не включены. Другие учебные проекты из соседних
папок не относятся к этому репозиторию.
