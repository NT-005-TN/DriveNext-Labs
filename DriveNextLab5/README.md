# DriveNext — лабораторная работа №5

Отдельный проект Android 12+, Kotlin, ViewBinding, ViewModel, корутины.
Открывайте эту папку в Android Studio. JDK 21, Android SDK 35.
Приложение на устройстве называется «DriveNext ЛР 5».

## Реализация

- Настоящая авторизация Supabase: email/пароль, Google OAuth с PKCE, обновление сессии, выход, восстановление пароля.
- Три шага регистрации: серверная учётная запись, приватные фотографии, профиль.
- Каталог и поиск через PostgREST; результаты не подменяются локальным списком.
- Профиль и смена аватара сохраняются на сервере. Для аренды нужны имя, фамилия и удостоверение.
- Детали, избранное Room в отдельной базе каждого пользователя, работа с БД вне главного потока.
- Бронирование: проверка дат, расчёт суммы, серверная запись, список, детали, отмена.
- Добавление машины: сохраняемый черновик, серверная запись, 1–5 фото, публикация только после загрузки.
- Нет Toast-заглушек Google, demo_token и искусственных задержек загрузки.
- Общие рабочие экраны переходов включены в лабы 3–5: из каталога можно действительно открыть детали и оформление, из настроек — бронирования и добавление машины.

RLS: каталог читают вошедшие пользователи; изменять машину может владелец.
Бронирования видит только создавший пользователь. Создание и отмена выполняются RPC.
Цена вычисляется на сервере, пересекающиеся аренды блокируются транзакционной блокировкой.
