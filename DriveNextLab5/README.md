# DriveNext — лабораторная работа №5

Самостоятельный Android-проект на Kotlin (минимальная версия Android 12), реализующий:

- информационный экран «Стать арендодателем»;
- ввод адреса расположения автомобиля;
- форму характеристик со `Spinner` выбора трансмиссии;
- проверку заполнения всех обязательных полей;
- множественный выбор до пяти фотографий;
- отображение миниатюр и экран успешного добавления автомобиля.

## Запуск

1. Откройте папку `DriveNextLab5` в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите приложение на эмуляторе или устройстве с Android 12+.

Авторизация и отправка регистрации пока работают в демонстрационном локальном режиме; подключение Supabase выполняется после добавления ключей проекта.
