# DriveNext — лабораторная работа №3

Самостоятельный Android-проект на Kotlin (минимальная версия Android 12), реализующий:

- прокручиваемый каталог автомобилей на `RecyclerView`;
- поиск через `SearchView` с отдельным экраном результатов;
- карточки автомобилей с действиями;
- нижнюю навигацию (`BottomNavigationView`);
- экран настроек и профиль со сменой аватара;
- выход из аккаунта с очисткой стека.

## Запуск

1. Откройте папку `DriveNextLab3` в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите приложение на эмуляторе или устройстве с Android 12+.

Авторизация и отправка регистрации пока работают в демонстрационном локальном режиме; подключение Supabase выполняется после добавления ключей проекта.
